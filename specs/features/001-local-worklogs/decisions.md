# Local worklogs decisions

Frozen decisions:

- `workledger` ships as one CLI binary.
- SQLite is the canonical local worklog authority in MVP.
- YAML is operator-managed config, not mutable runtime state.
- Local worklog IDs are opaque UUID strings generated by the CLI.
- Deleted-worklog tombstones are exposed only through existing `worklogs` commands.
- Guarded batch delete is an extension of `workledger worklogs delete`.
- `worklogs context`, `worklogs shift`, and `worklogs apply` are follow-up local scopes, not part of `001`.
- TUI work is deferred beyond MVP.
