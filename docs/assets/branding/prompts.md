# Workledger branding icon concepts

Generated on 3 November 2026 using the built-in image generation tool.

Context at exploration: the referenced “Audit TUI Repos” conversation recommended restrained, recognizable branding alongside real terminal screenshots. The original brief described Workledger as a local-first CLI and TUI for canonical worklogs, time planning, and reviewed reconciliation with remote trackers. The prompts below preserve that brief; the current [product positioning](../../media.md#product-positioning) leads with an agent-friendly CLI and presents the TUI as optional.

These are the original alternative concepts for review. Their PNG previews use an opaque dark background. ChatGPT recommended Ledger W; the [refined candidate and theme/size assets](ledger-w-refined/README.md) develop that direction further.

## Initial generation prompts

### Ledger W

```text
Use case: logo-brand.
Asset type: standalone branding icon concept for Workledger, an open-source local-first CLI and terminal UI for worklogs, time planning and reviewed reconciliation with Jira and Clockify. Audience: developers and coding agents. Brand qualities: precise, trustworthy, calm, efficient. Take the restraint of excellent terminal-tool README identities, with an original recognizable symbol.
Create ONE finished icon only on a genuinely transparent background, square canvas, centered with generous even clear space. Crisp flat vector-like graphic with smooth solid fills, bold simple silhouette, careful optical balance. It must remain recognizable at 24–32 pixels and be feasible to redraw as SVG later. No text, no wordmark, no caption, no multiple versions, no contact sheet, no mockup, no outer app tile, no watermark, no gradients, no shadows, no 3D. Use negative space intelligently and keep detail sparse.
Primary request: an original geometric W monogram built from a small number of interlocking rectilinear strips that also evoke precisely aligned worklog time blocks. The W must be instantly legible as the dominant silhouette; the ledger idea is a subtle second read. A compact, confident mark with consistent thickness, a few restrained softened corners and clean deliberate gaps. Single flat lavender fill inspired by the app's #CBA6F7 focus accent; no other colors. Avoid a generic zigzag, finance graph, mountains, bars in a chart, checkmark, page outline or clock. Make a memorable developer-tool brand symbol.
```

## Final refinement prompt

Each original icon was passed separately as an edit target. The initial transparent exports had visible edge artifacts; the final pass uses an opaque dark field.

```text
Use case: logo-brand. The input image is the edit target, a Workledger brand icon concept. Refine and clean this exact icon, keeping its distinctive silhouette, arrangement, proportions and main hue. Remove every colored fringe, glowing edge, shadow, texture, grain, speckle, gradient, lighting effect and transparency artifact. Redraw the symbol as absolutely clean smooth flat vector-like geometry with ONE uniform solid color per component, sharp professional edges and optical balance. Replace all transparent or black negative space, including all cutouts and the surrounding canvas, with one perfectly uniform solid dark background #1E1E2E. This is an opaque graphic: no transparent pixels anywhere. Keep the icon centered and with generous even padding on a square canvas. The foreground colors should be soft clean pastel hues from the original image. No text or captions. No additional shapes. No lighting. No bevels. No 3D. No glow. The result must look like a carefully authored flat SVG logo on a matte dark field.
```
